# عيادة د. هشام الخطاب — لوحة تحكم إدارة المرضى

لوحة تحكم ويب لإدارة مرضى العيادة، بواجهة عربية كاملة (RTL) وهوية بصرية طبية بسيطة.

## المزايا

- **شاشة ترحيبية** تظهر لمدة 3 ثوانٍ ثم تنقل إلى صفحة تسجيل الدخول.
- **تسجيل دخول مدير اللوحة** (حساب + كلمة سر).
- **بطاقة «مريض جديد»**: نموذج إضافة مريض (الاسم، الهاتف، العمر، الجنس، العنوان، الأمراض المزمنة، الحالة المرضية، التحاليل المجرأة، صورة الوصفة، ملاحظات). يرفض النظام إضافة مريض بنفس رقم الهاتف إذا كان مسجلاً مسبقاً.
- **بطاقة «مريض مراجع»**: بحث فوري بالاسم أو الهاتف مع اقتراحات، وعرض كامل بيانات المريض وسجل مراجعاته، مع:
  - **حفظ الكشفية PDF** — تنزيل كشفية طبية كاملة بصيغة PDF.
  - **مراجعة جديدة** — تسجيل تشخيص ووصفة جديدة تُحدّث تاريخ آخر مراجعة تلقائياً.
- **أرشيف المرضى**: جدول بكل المرضى من تاريخ الإضافة حتى الآن مع بحث سريع، ويُحدّث تلقائياً مع كل إضافة أو مراجعة.

## التقنيات

- واجهة أمامية: HTML / CSS / JavaScript خالصة (بدون إطار عمل).
- قاعدة البيانات: [Supabase](https://supabase.com) — جدولان: `patients` و `visits`.
- توليد PDF: مكتبة html2pdf.js.
- الاستضافة: Vercel، والمستودع على GitHub.

## البنية

```
index.html   — بنية الواجهات (الترحيب، الدخول، اللوحة، الأرشيف)
style.css    — الهوية البصرية
config.js    — مفاتيح الاتصال بـ Supabase وحساب المدير
app.js       — منطق التطبيق والاتصال بقاعدة البيانات
schema.sql   — بنية جداول قاعدة البيانات وسياسات الوصول
```
